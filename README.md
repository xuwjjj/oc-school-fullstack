# منظومة إدارة المدارس

مشروع كامل لإدارة المدرسة، يتكون من واجهة React/Vite وخادم Express وقاعدة بيانات SQLite عبر `sql.js`.

## بنية المشروع

- `client/`: الواجهة الحالية، ملفات المصدر في `src/` ومخرجات البناء في `dist/`.
- `server/`: واجهة API والمصادقة وقاعدة البيانات.
- `server/data/`: قاعدة البيانات المحلية، ولا تُرفع إلى Git.
- `legacy/`: نسخة HTML/CSS/JavaScript القديمة المحفوظة للأرشفة، وليست مدخل التطبيق الحالي.
- `logs/`: سجلات البناء والتشخيص.

## التشغيل على Windows

قبل التشغيل، أنشئ ملف إعداد محلياً:

```powershell
Copy-Item server\.env.example server\.env
node -e "console.log(require('node:crypto').randomBytes(48).toString('hex'))"
```

ضع القيمة الناتجة في `JWT_SECRET` داخل `server\.env`، ثم عيّن قيماً فريدة لـ `ADMIN_USERNAME` و`ADMIN_PASSWORD`. لا تشارك ملف `server\.env` أو ترفعه إلى Git؛ يجب استخدام أسرار مستقلة لكل بيئة. إذا سبق استخدام بيانات اعتماد مكشوفة، فغيّر كلمة مرور حساب المشرف وأسرار البيئة ذات الصلة.

```powershell
npm.cmd install
npm.cmd --prefix server install
npm.cmd --prefix client install
npm.cmd run dev
```

تعمل الواجهة عادة على `http://localhost:5173` وواجهة API على `http://localhost:4000`.

## البناء

```powershell
npm.cmd --prefix client run build
```

## استيراد الطلاب

تدعم صفحة سجل الطلاب ملفات CSV وTSV وTXT وExcel بصيغة XLSX. يمكن للملف أن يحتوي أسماء فقط، أو أعمدة الاسم والصف والشعبة وبيانات ولي الأمر. تُدار الصفوف والشُعب من صفحة «الشعب والصفوف».

يستطيع المعلم أو المشرف رفع قائمة أسماء من صفحة الصفوف والشُعب وتعيينها لشعبة محددة؛ الأسماء المسجلة مسبقاً في الشعبة نفسها لا تُكرر. وتتيح صفحة «استيراد درجات الطلبة» اختيار الصف والشعبة والمادة والاختبار والدرجة النهائية، ثم رفع ملف CSV أو TSV أو TXT أو XLSX يحتوي عمودي `name` و`score` (أو «اسم الطالب» و«الدرجة»). يُضاف الطالب إذا لم يكن مسجلاً في الشعبة، وتُحدّث الدرجة عند إعادة رفع المادة والاختبار نفسيهما.

ينشئ المشرف حسابات دخول المعلمين من صفحة الكادر التدريسي. التسجيل العام يبقى للطلاب فقط.

## الحضور والتقارير

يسجل المشرف الغياب مباشرة من قائمة الطلاب، ويُحفظ لكل طالب تاريخ وحالة الحضور. تعرض صفحة الحضور سجل الأيام السابقة وعدد الغيابات وتواريخها. ومن صفحة التقارير يمكن البحث عن طالب وعرض صفه وشعبته ودرجاته وسجل غيابه، ثم طباعة تقريره.

تعرض التقارير أيضاً الطلاب الذين لديهم ثلاثة أيام غياب أو أكثر، ويمكن تغيير الحد وتنزيل القائمة أو تقرير الطالب بصيغة CSV متوافقة مع Excel (UTF-8). استخدم «طباعة / PDF» لحفظ تقرير الطالب بصيغة PDF من نافذة الطباعة في المتصفح.

## النسخ الاحتياطية

ينشئ الخادم نسخة احتياطية عند بدء التشغيل، ثم كل 24 ساعة ما دام يعمل. تُحفظ النسخ في `server/data/backups/` ويُحتفظ بآخر 30 نسخة. يمكن للمشرف إنشاء نسخة فوراً أو تنزيلها من قسم التقارير. شغّل المشروع بانتظام لضمان إنشاء النسخ اليومية؛ إذ لا يعمل الجدول أثناء إيقاف الخادم.

## الأدوار

التسجيل العام ينشئ حساب طالب للقراءة فقط. إدارة بيانات المدرسة متاحة للأدوار المخولة، ويتم التحقق من الصلاحيات في الخادم.
